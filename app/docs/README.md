# Introduction

Welcome to the SETU documentation page. Here, you will find information to understand and use the SETU standards effectively. This documentation covers three modules of standards:
* [Purchase to Pay v2.0](./purchase-to-pay-v2/README.md) — ordering & selection, assignment, and reporting time & expenses (timecard) between staffing customers and staffing suppliers.
* [Planning and Scheduling](./planning/README.md) — planning constraints, planning requests and planning assignments.
* [Inquiry Pay Equity v2.0](./gelijkwaardige-beloning/README.md) — exchanging remuneration information to support equal pay for flex workers.

For each standard, you will find:
* An overview of the standard and the message specifications it contains;
* The supported business processes, scenarios and sequence diagrams;
* Additional usage notes.

The [API documentation](./api/README.md) section describes the REST API specifications (OAS) for all three standards, including general usage notes that apply across standards.
